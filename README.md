# BIWORSOURCING — Minimal Professional Website

Clean, minimal design with full section-by-section customization.

## Design
- Neutral black / white / gray palette (no heavy color grading)
- Professional, modern, content-first layout
- Fully responsive

## Admin — customize everything
| Tab | Control |
|-----|---------|
| **Page Sections** | Hero, About, Principles, Services, Process, Clients, Products, Gallery, Advantages, Contact — edit text, lists, show/hide |
| **Products** | CRUD + image upload |
| **Gallery** | Factory photos + image upload |
| **Company** | Name, email, phone, WhatsApp, address, footer |
| **Logo** | Logo + favicon upload |
| **SEO** | Meta title, description, keywords |

Password: `biwor2024`

## Run
```bash
npm install
npm run dev
```
- Site: http://localhost:3000
- Admin: http://localhost:3000/admin
